# TP Selenium CI/CD

## Avantages observés
- Les tests automatiques évitent les vérifications manuelles
- Le pipeline CI détecte immédiatement les erreurs

## Défis rencontrés
- Problèmes de drivers Selenium sur GitHub Actions
- Nécessité d’attendre les éléments avec WebDriverWait

## Métriques importantes
- Couverture de code (pytest-cov)
- Nombre de tests réussis
- Temps d’exécution du pipeline
